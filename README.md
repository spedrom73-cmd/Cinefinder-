🎬 CineFinder

Descobre o filme ou a série a partir de um vídeo!

O CineFinder é um projecto de aplicação Android desenvolvido com o objectivo de identificar filmes e séries através da análise de pequenos excertos de vídeo, utilizando técnicas de visão computacional e, futuramente, inteligência artificial.

🎯 Objectivo

Facilitar a descoberta de filmes e séries quando o utilizador conhece uma cena, mas não sabe o nome da obra.

✨ Funcionalidades planeadas

- 📹 Seleccionar vídeos a partir do dispositivo Android.
- 🔍 Analisar fotogramas extraídos dos vídeos.
- 🎞️ Comparar imagens com referências de filmes e séries.
- 📊 Apresentar possíveis correspondências e pontuações de semelhança.
- 📱 Disponibilizar uma interface simples e intuitiva.
- 🧠 Evoluir para sistemas de reconhecimento visual mais avançados.

🛠️ Tecnologias

As tecnologias serão definidas conforme a arquitectura final do projecto, podendo incluir Kotlin, Jetpack Compose, Python, FastAPI, OpenCV e ferramentas de inteligência artificial.

🚧 Estado do projecto

Em desenvolvimento. O objectivo inicial é criar uma versão Android funcional para testes, melhorando gradualmente o reconhecimento, o desempenho e a experiência do utilizador.

🌍 Visão

Tornar a descoberta de filmes e séries mais simples, acessível e inteligente, através da tecnologia.

🤝 Contribuições

Sugestões, ideias e contribuições construtivas são bem-vindas para ajudar a melhorar o CineFinder.
